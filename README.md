# Alexa-like Virtual Assistant

This project is a simple virtual assistant similar to Amazon Alexa, built using Python. It can recognize voice commands and respond to various queries such as playing songs on YouTube, telling the time, providing Wikipedia summaries, telling jokes, and more.

<h2>Features</h2>

-  Voice Recognition: Listens to commands and recognizes them using Google's Speech Recognition API.
-  Text-to-Speech: Responds to commands using text-to-speech functionality.
-  Play Music: Plays songs on YouTube.
-  Tell Time: Provides the current time.
-  Wikipedia Summary: Fetches a summary of a topic from Wikipedia.
-  Jokes: Tells a random joke.

<h2>Requirements</h2>

-  Python 3.x
-  speech_recognition library
-  pyttsx3 library
-  pywhatkit library
-  wikipedia library
-  pyjokes library

<h2>Installation</h2>

-  Clone the repository:

``` bash
git clone https://github.com/sadhik-ali/Alexa_Python.git
cd your-repo-name
```

-  Install the required libraries:

``` bash
pip install speechrecognition pyttsx3 pywhatkit wikipedia pyjokes
```

<h2>Usage</h2>

-  Run the script:

``` bash
python main.py
```

The virtual assistant will start listening for commands. Use the keyword "Alexa" in your commands. For example:

-  "Alexa, play Shape of You"
-  "Alexa, what is the time?"
-  "Alexa, who the heck is Albert Einstein?"
-  "Alexa, tell me a joke"
